# K H Plumbing Supply Inc.

Website for K H Plumbing Supply Inc. in San Francisco.

## Run locally

Prerequisite: Node.js.

```sh
npm install
npm run dev
```

## Build and deploy

```sh
npm run build
```

The production website is written to `dist/`. Upload the contents of that
folder to any static web host or web server. No server-side runtime, API keys,
or host-specific services are required. Relative asset paths allow the site to
be served from a domain root or a subdirectory.

To check the production build locally, run `npm run preview`.
